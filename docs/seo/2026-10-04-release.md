# 検索流入と公開一覧の改善（2026-10-04）

## 実装

- 一覧下部のAdMaxは表示領域の600px手前で一度だけ読み込む。枠を確保し、IntersectionObserver未対応なら即時読み込む。AdSense/GTMの設定は維持。画像配信元へpreconnect、アイコンフォントはswapで文字描画を妨げない。
- 未ログインのサークル一覧から編集・カレンダー・ギャラリー用JS/CSSを外し、ナビゲーションとRailsリンク処理だけを遅延読み込み。ログイン・編集画面は既存の構成を使用。
- 先頭の一覧画像は eager/high、後続とアイコンはブラウザ標準のlazy読み込み。既存の画像枠を維持。
- JSON-LD、空判定、カードが同じ読み込み済み一覧を共有。大量の口コミ・日程を読み込まない既存の取得制限を維持。
- 一覧カードへ保存済み参加費・年代を追加。データがなければ表示しない。学生の参加条件を保証する説明を撤去し、参加条件の確認を案内。
- 地域・競技一覧に選び方と関連する募集／施設への導線。施設から募集一覧へは301を挟まず正規URLへ移動。
- sort・広告計測パラメータ・page=1をcanonicalから除外。page=2以降は独立したページ番号を維持。構造化データは絶対URLと連続順位。
- 無効な地域、地域に属さない市区町村、不正なsort/page、範囲外のページ番号は404。空の有効一覧・空の開催日はnoindex。掲載がある過去の開催日は維持。
- 任意内部検索はnoindex,follow。2026-08-06〜09-30にGSCでクリック実績のある218検索語（453 URL、779クリックを確認）の入口は保護。検索語本文はコミットせずSHA256集合で照合。保護対象でも空ならnoindex。今後の見直しは、長期の流入を確認し専用一覧への移行を検討する。
- サイトマップから任意キーワード・旧URLを除外し、公開団体がある地域・競技・地域×競技の正規URLを追加。個別団体のlastmodは更新日時。地域一覧には架空の更新日時を付けない。

## 判定と残る観測

直近28日の基準値：GSCクリック74,558、表示702,531、平均順位8.45。モバイルCWV不良2,068／改善必要6,557（10月2日）。単一のPSIラボ測定はスコア57、LCP16.4秒。GSCの107万件の未登録・20,361件の過去5xxは履歴値で、今回の反映だけで即時ゼロにはならない。

GSCのクリックはPVではない。GA4等の自然検索セッション・PV・問い合わせの実績との照合が必要。新しい分析アカウントや推測のPVは作成していない。順位やCWVの効果は再クロールと実ユーザー計測後に評価する。

優先観測URL：東京インカレ、東京／大阪／神奈川の地域一覧、東京バスケ／バドミントン、福岡登山タグ。非指名語・同じデバイスで前28日・前年同時期と比較。4〜8週間で改善群を評価し、既存流入を守る。独自の地域ガイドや施設情報の追加には団体・施設の実際の事実が必要なため、推測の紹介文は生成しない。

## デプロイと復旧

masterへのpushで既存deploy_prodワークフローがテスト後にserver4/server5へ反映。新規DBマイグレーションなし。既存デプロイスクリプトの指定済みマイグレーション確認は実行される。アセット再生成後、Pumaを順番にホット再起動してウォームアップする。サイトマップは既存の日次タイマー（00:00 JST）で次回生成時に更新。

主要URLの5xx、メニュー・検索・画像の不具合が発生した場合はこのコミットをrevertした日本語コミットをmasterにpushし、同じワークフローで復旧する。強制pushや本番DBの直接編集は行わない。旧アセットは既存デプロイ方式で保持。

追加検証：初回反映後のPSIは55点・LCP16.1秒で速度改善はまだ十分でない。ブロック推定削減時間は3,020ms→1,200ms、未使用JSは575KiB→318KiB。単発ラボ値で効果を断定せず、広告遅延読み込みを追加して再測定する。
