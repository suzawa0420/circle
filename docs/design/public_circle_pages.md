# サークル詳細・活動日・口コミ・Q&A・ブログの共通ルール

- PC（992px以上）は、中央の外枠960px・左右余白24px・本文560px・間隔32px・右欄320px。ヘッダーなど共通領域の最大幅は912px。本文カードと右欄の端は各タブで揃える。
- 992px未満は1列にし、狭い画面では左右14pxを目安にする。画面全体を横スクロールさせない。操作はアイコンだけにせず、44px程度の操作領域と読み上げ用ラベルを確保。
- 本文欄の活動カレンダー・口コミの評価とカード・Q&Aフォームと一覧・ブログカードは全幅。カードは淡い枠、角丸10px程度、内側余白14〜16px。保存・共有・日付・場所などに限定して Lucide アイコンを使用し、星は口コミの評価だけに使う。
- 詳細は表紙／活動予定／写真・動画／構成／紹介／口コミ／Q&A／公開された最新ブログ／主催者情報とリンク／似たサークル／編集部の準備ガイドの順。主催者プロフィールは公開条件を満たす場合のみ。種目・都道府県が共通する募集中の公開サークルは既存の順序で最大3件。準備ガイドは参加者向けの公開記事から種目を優先し、共通記事を含めて最大3件、0件時は非表示。
- 未返信報告は、3日以上返信がなく報告した参加者の重複しない人数を、現行の文言で表示。0人なら枠ごと非表示、1年以上更新なしとは別条件。募集・公開・管理者・投稿の既存判定を変えない。
- 検証ではスマホとPCで5タブを巡回し、公開/非公開、予定と口コミがない場合、保存/解除、問い合わせ、Q&A投稿条件、ブログの画像あり/なし、主催者画面、既存URLとSEO要素を確認する。
