# ブログ・サークルの判定理由

自動判定で確認待ちにする際、users / blogs の moderation_reasons に条件コードと判定時の説明文、moderation_checked_at に判定日時を保存する。公開・保留の既存条件は変更しない。判定条件に該当しなくなっても、従来どおり確認待ちの自動解除は行わず、最後に保留した理由を残す。運営が確認済みにした場合も保存済み理由は保持し、詳細では過去の判定理由として表示する。

表示先はマスター管理画面のサークル・ブログ一覧、主催者一覧・詳細と、マスターによるサークル・ブログ詳細の閲覧。一般利用者・通常の主催者には表示しない。プロフィールの不足項目、NG指定、主催者の非公開指定、利用停止理由も管理画面で確認できる。

導入前の投稿の当時の理由は復元できない。現在の本文の重複と、作成時刻付近の先行投稿数を参考情報として表示し、当時の理由が未保存である旨を明示する。判断時以降の修正・削除で該当条件を確認できない場合も、その旨を表示する。既存投稿の公開状態・本文は移行時や画面閲覧時に変更しない。公開停止の具体的理由が未記録の場合は理由を推測せず未記録と表示する。

既存ブログ一覧の重複確認は本文をまとめて集計し、投稿ごとの全件走査を避ける。
