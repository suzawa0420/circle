# ブログ・サークルの判定理由

自動判定で確認待ちにする際、users / blogs の moderation_reasons に条件コードと判定時の説明文、moderation_checked_at に判定日時を保存する。公開・保留の既存条件は変更しない。判定条件に該当しなくなっても、従来どおり確認待ちの自動解除は行わず、最後に保留した理由を残す。運営が確認済みにした場合も保存済み理由は保持し、詳細では過去の判定理由として表示する。

表示先はマスター管理画面のサークル・ブログ一覧、主催者一覧・詳細と、マスターによるサークル・ブログ詳細の閲覧。一般利用者・通常の主催者には表示しない。プロフィールの不足項目、NG指定、主催者の非公開指定、利用停止理由も管理画面で確認できる。

導入前の投稿の当時の理由は復元できない。現在の本文の重複と、作成時刻付近の先行投稿数を参考情報として表示し、当時の理由が未保存である旨を明示する。判断時以降の修正・削除で該当条件を確認できない場合も、その旨を表示する。既存投稿の公開状態・本文は移行時や画面閲覧時に変更しない。公開停止の具体的理由が未記録の場合は理由を推測せず未記録と表示する。

既存ブログ一覧の重複確認は本文をまとめて集計し、投稿ごとの全件走査を避ける。

## 性的サービスの掲載対策

サークルの新規登録と編集時に、名称・詳細・目標・活動場所・日時・参加条件・料金・外部連絡先など公開プロフィールのテキストを検査する。HTML・文字参照を除去し、全半角・大小文字を統一し、空白・記号・不可視文字による禁止語の分割にも対応する。既存の禁止語に加え、デリバリーヘルス・性服務・外送茶などの明確な表現は入力エラーとして保存を拒否する。

「深夜舒壓／深夜舒压」を含む場合は、連絡先の有無・数に関係なく `adult_service_promotion` として確認待ちにする。登録内容は保存するが、一般公開・検索一覧には出さない。複数の外部連絡先、夜間活動、「舒壓」だけではこの条件に該当しない。判定理由を運営画面で確認し、既存の公開・停止操作で判断する。確認待ちは自動解除しない。

導入時のマイグレーションで、同じ表現を含む既存レコードの審査状態がclearの場合のみ確認待ちへ変更し、理由・判定日時を保存する。既に確認待ち・停止中の判断や投稿内容は変更しない。ロールバックで自動公開し直さず、運営による確認で解除する。画像内の文字や、外部リンクの遷移先は検査対象外。

2026-10-21：「高品質なデリバリーサービス」「高級なデリバリーサービス」「厳選されたデリバリーサービス」も `adult_service_promotion` の確認待ち条件に追加。「高品質／高級」は「な」がない表記も対象とし、同じ正規化を適用する。連絡先の有無によらず判定するが、「デリバリーサービス」「完全予約制」「本人対応」「対面でのお支払い」単独では保留しない。通常の宅配・食事会などへの影響を抑えるため、明確な禁止語とは分けて運営確認の対象とする。

マイグレーション `20261021000000` は追加表現に一致する既存のclear投稿のみ確認待ちへ移す。投稿内容・主催者・既存の確認待ち／停止判断は変更せず、同じマイグレーションを再実行しても判定日時と理由を上書きしない。
