# メッセージの編集・削除

- 参加者・主催者・練習試合の両主催者は、自分が送信した投稿を元の送信時刻から12時間未満の間に編集・削除できる。自動案内は対象外。
- メッセージ内の右下に編集・削除を配置。本文のみ編集でき、写真は投稿ごと削除できる。編集後も送信時刻と期限は変わらない。
- 編集済みの表示、削除した人の名前を含む通知を本人・相手・マスターの会話履歴、通報詳細、スパム確認に表示する。通常の定期更新にも反映する。
- 削除は論理削除。本文と暗号化された写真は運営確認の証跡として保持し、通常画面・管理画面では非表示にする。写真の取得も全アカウントで拒否する。
- 参加者の編集本文はスパム再判定する。配信保留・拒否済みの投稿は編集しても保留とし、削除済みの投稿は配信許可できない。
- 削除した投稿を返信なしの判定に使わない。元の既読・受付履歴は維持する。

## デプロイと復旧

`20261019000000` は nullable な `edited_at`・`deleted_at` の追加のみ。5秒のロック待機制限を設ける。両サーバーのアプリ更新前に既存デプロイスクリプトで適用する。

不具合時は修正コミットを同じ検証・デプロイ経路で反映する。DBカラムと削除内容を隠す表示・写真取得拒否は残す。単純に機能追加前のコードへ戻すと論理削除済みの本文・写真が再表示されるため、そのような巻き戻しは行わない。DBのロールバックは不要。
