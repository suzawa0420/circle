# サークルレベル

主催者向け画面・特典申請・未返信の案内はレベル表記に統一する。
小数の加算は次のレベルへの進捗として扱い、画面上で別の単位に換算しない。
演出の再生・お試しボタンは置かず、実際の通知時の自動演出だけを残す。
保存済みスコアの計算方法と上限・加算・減少の条件は変更しない。

- 既存の `cb_point` を保持し、表示は小数第1位に丸めて整数部分をLv.0〜100に制限する。小数部分は進捗バーに使う。
- 配点と削除時の再計算、未返信報告の減点、`user_time` による既存の1年未更新判定を維持する。日次・月次の獲得上限は設けない。
- 人気順は従来の募集状況の優先順を維持したうえで、レベル降順・`last_post` 降順・ID降順。同レベルでは小数や100超の累計を比較しない。
- `updated_at` / `user_time` と順位用の `last_post` を区別する。ブログ新規公開・活動予定新規登録・質問への初回回答だけで順位日時を更新する。新着順は変更しない。
- 口コミの配点は従来の高評価1件2.0を維持。口コミ依頼の案内から既存のメッセージ画面へ進める。

## サークル情報入力特典（2026-10-18）

ヘッダー画像・プロフィール画像・紹介文（タグ等を除いて100文字以上）・
活動エリアと場所・活動の曜日と時間帯・募集するメンバーや参加条件・参加費の
7項目を保存すると、1サークルにつき初回限定で5ポイントを付与する。
画像はDBのアップロード済み識別子で判定し、デフォルト画像URLは達成と扱わない。
参加費は「無料」「0円」も可。未設定項目はマイページから編集欄へ案内する。

所有者による登録・基本情報の保存時、または既存サークルの所有者マイページ訪問時に
行ロック内で一度だけ付与し、ランキング用の保存済みスコアも再計算する。
一括バックフィルはしない。獲得後の編集・画像削除でも特典は取り消さず、
再入力しても重複付与しない。既存の1年未更新・未返信・違反判定は維持する。

特典の通知済み状態は端末間で共有する。初回マイページでの通常の基準値設定とは
別に特典を通知するため、初回訪問でも実際に0→5などの達成体験ができる。
上限Lv.100や減点等でレベルが上がらない場合も、入力完了と5ポイント獲得を案内し、
架空のレベル上昇は表示しない。主な導線は引き続きスケジュール登録。

`20261018000000` で獲得・通知日時のnullable列を2つ追加する。
ロールバックは打ち消しコミットを通常手順で反映し、追加列は残してよい。

## 再投稿の判定

`circle_activity_fingerprints` にサークル・種類・SHA256だけを保存する。ブログは本文、活動予定は日付・開始終了時刻・会場、質問は質問文を照合する。空白と文字幅を正規化し、質問はレコードIDも記録して回答の消去・再入力を区別する。本文や回答の全文はこのテーブルに保存しない。

既存投稿は編集・削除の前に記録する。導入前に削除された投稿は復元・照合できない。似た内容を意味から判定する仕組みではない。再投稿は通常の件数加算に戻るが、順位日時は更新しない。

- `20261002030000`: 再投稿照合テーブル（サークル削除時に連動削除）
- `20261002040000`: レベル順の式インデックスをCONCURRENTLY作成

既存の配点・既存ポイントを一括再計算するデータ移行は行わない。1か月20・1年50などの新しい減点ルールは未導入。
