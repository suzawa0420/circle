# サークルレベル

- 既存の `cb_point` を保持し、表示は小数第1位に丸めて整数部分をLv.0〜100に制限する。小数部分は進捗バーに使う。
- 配点と削除時の再計算、未返信報告の減点、`user_time` による既存の1年未更新判定を維持する。日次・月次の獲得上限は設けない。
- 人気順は従来の募集状況の優先順を維持したうえで、レベル降順・`last_post` 降順・ID降順。同レベルでは小数や100超の累計を比較しない。
- `updated_at` / `user_time` と順位用の `last_post` を区別する。ブログ新規公開・活動予定新規登録・質問への初回回答だけで順位日時を更新する。新着順は変更しない。
- 口コミの配点は従来の高評価1件2.0を維持。口コミ依頼の案内から既存のメッセージ画面へ進める。

## 再投稿の判定

`circle_activity_fingerprints` にサークル・種類・SHA256だけを保存する。ブログは本文、活動予定は日付・開始終了時刻・会場、質問は質問文を照合する。空白と文字幅を正規化し、質問はレコードIDも記録して回答の消去・再入力を区別する。本文や回答の全文はこのテーブルに保存しない。

既存投稿は編集・削除の前に記録する。導入前に削除された投稿は復元・照合できない。似た内容を意味から判定する仕組みではない。再投稿は通常の件数加算に戻るが、順位日時は更新しない。
