# メッセージの宣伝スパム確認

参加者からのメッセージを、主催者が初めて返信するまで判定する。主催者の返信後は通常の会話として本文判定を行わない。既存のメール認証、送信上限、ブロックは引き続き適用される。画像の中の文字は判定しない。

## 判定

5点以上を配信保留とする。成人向けサービスの宣伝表現4点、予約・料金等の勧誘表現2点、複数の外部リンク・連絡先2点、6個以上のハッシュタグ1点、運営が確認済みの誘導先5点。

同じ参加者による30分以内の初回返信前の投稿を最大60件比較する。別の2サークル以上へ50文字以上の同一・類似文があれば4点、別の7サークル以上への問い合わせは1点。比較では全角・半角、大文字・小文字、空白、句読点の差を除き、3文字ずつの組の一致率90%以上を類似文とする。短い挨拶、外国語、LINEという単語だけでは保留しない。

## 運用

マスター管理画面の「スパム確認」に理由・点数・本文を表示する。保留・スパム確認済みの投稿は送信者と運営だけが閲覧でき、相手の一覧、未読数、通知、画像取得から除外する。運営の閲覧は既読にしない。

「配信を許可」で新着として配信し、通常の通知予定を作る。配信時刻順で表示し、古い投稿の許可でも閲覧済み扱いにしない。「スパムと確認」で配信せず、投稿内のURLのドメインとパスを次回判定に使用する。Telegram等のサービス全体は遮断しない。判断済み投稿は再処理しない。自動削除・自動アカウント停止は行わない。

導入直後は保留投稿を確認し、誤検知の理由を見ながら `ChatSpamDetector::REASONS` の条件・点数を調整する。既存メッセージは再判定せず配信済みとして保持する。
