# デザイン統一の確認記録（2026-10-02）

## 変更範囲

アプリケーション共通レイアウトに `cb-site` を付け、既存画面を共通トークン・mixinに接続した。機能やフォームの送信先を維持したまま、文字、配色、余白、角丸、カード、ボタン、入力欄、補足・エラーの表示を揃えた。

- トップ：公式リスの導入、カテゴリー・地域のカードと間隔。
- 検索：サークル、ブログ、対戦相手、コート情報の検索欄・見出し・結果カード。
- 詳細：サークル、ブログ、対戦相手、施設、活動予定、Q&A、口コミ。
- 管理：主催者マイページ、サークル情報、活動エリア、プロフィール、予定・ブログ投稿、対戦募集、リンク、施設編集。
- 参加者：マイページ、プロフィール、アカウント情報、公開プロフィール。
- メッセージ：一覧、会話本文、補足、入力欄に共通色・文字サイズ。
- 静的ページ：About、FAQ、利用規約、プライバシーポリシー。
- 共通導線：PCヘッダーを共用。スマホの役割別下部ナビとサークル切り替えを維持。
- 検索の並び順を共有partialに整理し、キーワードを維持・古いページ番号を解除。
- 質問の編集URLの既存500エラーを解消し、回答編集フォームがある詳細ページへ遷移。

## 確認範囲の限界・今後の運用

- ブラウザーの画面幅による検証。実機Safariのキーボード表示は今回の確認には含めない。
- ローカルでは広告、計測、Cloudflareの外部フレームを制限している。これらの内部表示は検証対象外。
- 各データ行を総当たりするのではなく、共通テンプレートを役割別・画面幅別に確認。画像枚数や長い名前など新たな条件の不具合は、そのテンプレートの確認項目に追加する。
- メールテンプレートと運営専用レイアウトは対象外。外部ウィジェットや印刷用の表には専用レイアウトを残す。
- 既存セレクターとの接続は `_site_design.scss` に集約した。今後の新規部品は `_design_components.scss` の `.cb-*` を使い、旧画面を変更するときは接続用ルールと古い宣言を整理する。
