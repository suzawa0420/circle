# 一覧の自分だけのメモ

- 会話一覧を相手の名前・最新メッセージ1行・日時と未読数・直接入力できるメモ欄に整理する。自分のサークル名、受付済み表示、参加者評価の通常表示は省く。未返信ペナルティや欠席申告などの重要な案内は残す。
- 300文字までの1行メモ。入力が700ms落ち着いた時とフォーカスが外れた時に保存する。日本語変換中は保存を待つ。
- 保存中・保存済み・保存失敗と再試行を表示する。通信中の追加入力は順番に保存し、古いリクエストによる上書きを防ぐ。未保存のままページを移る場合は保存を待ち、失敗時は現在の画面と入力を維持する。
- メモの所有者は参加者または主催者のログインアカウント。練習試合の両主催者も別々に保持する。主催者交代で前任者のメモは引き継がない。
- 相手の画面、メッセージ本文、ポーリング、通知メール、マスター管理画面にメモを表示しない。リクエスト本文は既存の `body` パラメータフィルターでログから除外する。
- メモ保存でメッセージ件数・既読・会話自体の更新時刻は変更しない。一覧は、自分に見えるメッセージの送受信・編集・削除日時と、自分のメモの更新日時のうち最新のものから並べる。相手のメモや既読の更新は並び順に影響しない。保存後、入力欄からフォーカスが外れると現在のページ内でも並べ替える。

## デプロイ

`20261019010000` で専用テーブルを追加する。所有者の排他制約・アカウントごとの一意制約・削除時の外部キー連鎖削除を含む。両サーバーのアセット準備・マイグレーション後にアプリを順次再起動する。

復旧時はこの変更前の `64ccee0f6` 以降をベースに修正・巻き戻しコミットを作り、通常のデプロイで反映する。メモのテーブルとデータは保持し、DBの巻き戻しは行わない。メッセージの論理削除を保護する既存実装も維持する。
