# 2026-10-14 検索・サークル詳細の速度と操作性

## 変更

1. 詳細ヘッダーに960×384の独立したWebP派生画像を追加。先頭だけeager/high priorityとし、匿名詳細で同じURLをpreloadする。元画像・既存400×160一覧画像は維持。変換失敗は既存の元画像fallbackを利用。
2. 同じタブで検索結果から詳細へ進むと、戻るリンクに条件・ソート・ページを保持。sessionStorageに30分だけ保存し、明示的に戻った時にスクロール位置を復元。外部URL、期限切れ、直接訪問、ストレージ禁止時は通常の一覧に戻る。
3. 既存の公開レベル順部分索引migrationを反映対象へ追加。CONCURRENTLY作成後にvalid/readyを確認し、失敗ならサーバー切替前に停止する。行データ変更なし。
4. 匿名詳細だけ専用JS/CSSへ切替。編集用・カレンダー用ライブラリを外し、画像はブラウザ標準lazyを使用。関連投稿Swiper、問い合わせ警告、ナビ、Rails UJSを維持。ログイン利用者は従来アセットを維持。
5. キーワード・種目・地域・市区町村・カテゴリ・タグ・募集内容・年齢の有効な条件を個別解除できるリンクを追加。他条件とソートを保持し、ページはリセット。canonical landingも対応。
6. 0件画面に一条件を外す再検索リンクを追加。OR条件の募集内容・年齢層は項目全体を外し、検索範囲を狭めない。候補件数の先行照会・ページ先読みはしない。

共通CSSの単独コンパイルで発見した施設一覧partialのpalette import不足も補正。
