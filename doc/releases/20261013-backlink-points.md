# リンク設置特典（10ポイント）

- 主催者管理画面のサークルレベルから「特別ポイントを獲得する」へ。
- `/circles/:circle_id/backlink_request` にロゴダウンロード、各サークルの公開URL、バナー／文字リンク用HTML、掲載先URLの申請フォームを用意。
- ご自身のサイトのトップページ・フッター等への掲載を推奨。サークル単位で1回。差し戻し後は修正・再申請可。承認後・取り消し後の再申請は不可。
- 申請・再申請時に `circlebook26@gmail.com` へ通知。保存確定後に専用メールジョブを実行。一時失敗は最大5回試行（既存Active Jobアダプターを利用）。
- `/super_admin/backlink_requests` で確認中／付与済み／差し戻し／取り消しを確認。承認で10ポイントを計算に加え、取り消しで除外。差し戻し・取り消し理由は必須で主催者にも表示。
- DBのサークルIDの一意制約と行ロック、状態遷移制限で重複申請・二重付与を防止。承認・取り消し日時と最終審査管理者を保存。
- 通常の得点再計算で特典を維持。既存の違反・1年以上更新なしの得点ルール、Lv.100上限は適用される。特典の承認はランキングの活動日時を更新しない。

## 反映時

`20261013100000_create_backlink_requests.rb` のマイグレーションとアセット生成が必要。スキーマ適用後に新コードを起動する。本番未反映。ロールバック時は旧コードへ戻してテーブルを残す（申請履歴保全）。
