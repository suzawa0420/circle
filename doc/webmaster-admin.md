# ウェブマスター専用管理

## 入口と権限

- ログイン：`/webmaster/login`、管理トップ：`/webmaster`。
- 主催者・参加者と別のDeviseスコープ、別テーブル `webmasters` を使用する。
- ウェブマスターはID 1の1件のみ。モデル検証とDB制約の両方で制限する。
- 公開の新規登録、パスワードリセット、アカウント編集APIは提供しない。
- `AdminUser` のID、メールアドレス、旧moderator列による管理権限は廃止。旧ID 1も通常の主催者として扱う。
- 管理トップにサークル・主催者、チャット通報、ブロック、無効メール、検索キーワード、入力エラー記録、施設管理を集約。
- サークル・ブログ・質問・施設等の旧運営向け権限も専用セッションに移行。チャット相手としての代理送信権限は与えない。
- 30分の無操作でセッション失効。パスワード10回失敗で30分ロック。IP単位の既存ログイン回数制限にも含める。
- 管理画面は広告・GTMを省略し、no-store、noindexを指定。

## 初期アカウント

## メッセージ管理

`/super_admin/conversations` に全会話の一覧を追加。最新メッセージ順に30会話ずつ表示し、サークル名・参加者ニックネームで検索可能。
各会話の最新本文の抜粋、発言者、日時、ブロック状態を確認できる。詳細では主催者と参加者の発言を区別し、時系列で50メッセージずつ表示。初回は最新ページを開き、ページ切り替えで過去の履歴も確認できる。

## 利用停止・参加者管理・通報対応（2026-10-01）

- 管理トップ／共通メニューの「参加者管理」から参加者を検索（ニックネーム・メール）し、停止状態で絞り込める。主催者の検索にも切り替え可能。
- 詳細には公開された受信口コミ、会話、関連会話の通報を表示。通報には通報者の役割を表示し、そのアカウントへの違反認定とは区別する。
- 主催者・参加者の停止／解除には専用確認画面を使用。停止理由は運営専用。停止中は当人の新規問い合わせ、チャット送信、口コミ投稿・編集を禁止する。主催者停止中はそのサークルへの新規問い合わせも禁止。
- ログイン、履歴閲覧、通報、本人の口コミ削除は可能。既存のサークルや口コミの公開状態は変更せず、既存会話の相手方の送信も止めない。サークル投稿等、チャット以外の編集権限は今回の停止対象外。
- 解除しても口コミ期限は延長しない。
- 主催者削除は旧エンドポイントからも確認画面へ誘導。サークル・会話・メッセージ・受信口コミの件数と関連データ削除の説明を表示し、15分有効の対象・操作別確認トークンを要求する。件数は確認画面表示時点。参加者の削除機能は追加しない。
- 通報は「未対応／確認中／対応済み」、状態別絞り込み、運営専用メモ（4,000文字）に対応。再オープン時には解決日時をクリア。既存の解決済み通報は移行時に引き継ぐ。
- 管理操作はウェブマスター限定、no-store／noindex。メッセージ画面から主催者・参加者の管理詳細へ移動できる。
- 追加マイグレーション: `20261001050000_add_account_moderation.rb`。ローカル開発・テストDBへ適用済み。本番には未適用。
- テスト: `test/integration/webmaster_accounts_test.rb`（権限、検索、確認トークン、停止・解除、投稿制限、通報状態・メモ、旧削除導線、停止者の旧口コミ削除）。
